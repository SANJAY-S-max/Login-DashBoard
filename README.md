# Login & Dashboard UI 🔐

A simple, responsive **Login and Dashboard** frontend built purely with HTML, CSS, and vanilla JavaScript. 

## 🌟 Features
- Clean and modern user interface
- Interactive login form with client-side validation
- Dashboard layout structure
- Responsive design for different screen sizes

## 🛠️ Technologies Used
- **HTML5:** For the basic structure and layout
- **CSS3:** For styling, layout, and visual effects
- **JavaScript (Vanilla):** For basic interactivity and form handling

## 🚀 Getting Started

Since this is a static frontend project, no build tools or servers are required!

1. Clone the repository:
   ```bash
   git clone https://github.com/SANJAY-S-max/Login-DashBoard.git
   ```
2. Navigate to the project folder:
   ```bash
   cd Login-DashBoard
   ```
3. Open `index.html` directly in your favorite web browser to see it in action!
